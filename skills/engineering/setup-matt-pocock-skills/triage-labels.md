# Triage Labels

The skills speak in terms of canonical triage labels across three dimensions. This file maps those labels to the actual label strings used in this repo's issue tracker.

| Dimension | Label in mattpocock/skills | Label in our tracker | Meaning |
| --------- | -------------------------- | -------------------- | ------- |
| Category  | `bug`                      | `bug`                | Something is broken |
| Category  | `enhancement`              | `enhancement`        | New feature or improvement |
| Effort    | `low-effort`               | `low-effort`         | Small, well-bounded work |
| Effort    | `medium-effort`            | `medium-effort`      | Moderate implementation or investigation effort |
| Effort    | `high-effort`              | `high-effort`        | Complex, ambiguous, or cross-cutting work |
| State     | `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue |
| State     | `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| State     | `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent |
| State     | `ready-for-human`          | `ready-for-human`    | Requires human implementation |
| State     | `wontfix`                  | `wontfix`            | Will not be actioned |

When a skill mentions a canonical label (for example, `high-effort` or `ready-for-agent`), use the corresponding label string from this table.

Edit the `Label in our tracker` column to match whatever vocabulary you actually use.
